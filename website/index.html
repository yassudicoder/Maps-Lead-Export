enforcement

The promises, and how the code keeps them.

Collects only what you see, in your own tab.
Zero host permissions and no content scripts in the manifest. The only injection path is your toolbar click, which grants activeTab for that one tab. A full page reload drops the grant and the panel asks for another click.
Never moves the page or opens places on its own.
The collector only observes. The single synthetic action is relaying one fresh gesture of yours to a card’s existing link: gestures older than 5 seconds are refused, one navigation may be in flight at a time, and only cards Maps has already drawn are eligible. No queue, loop, timer or batch path exists in the code.
Nothing leaves your computer.
The codebase's one fetch reads its own bundled selector file — nothing addresses the network. Session, presets, column choices and the exported-places memory live in chrome.storage.local; the CSV goes to Downloads; diagnostics go to your clipboard only. No server, no account, no payment code.
A field Maps did not show is null, never a guess.
Tri-state website status with a website_source column separating card inference from detail-page fact. Reviews export blank rather than zero; unknown distance exports blank rather than 0; addresses are reported exactly as Google serves them, errors included.
It stops rather than export rubbish.
A parse-health circuit breaker: fewer than half of visible cards parsing across two consecutive scans, with at least eight cards seen, halts collection and reports that the layout moved — the live percentage stays visible in the panel.
The exported-places memory knows nothing about the businesses.
The index stores place identifiers and timestamps only — no names, no addresses — capped at 50,000 with oldest-first eviction, and is inspectable, downloadable as CSV and erasable from the options page.
On a verification check, it steps aside.
On detecting a challenge the collector detaches its observers and the panel asks you to solve the check yourself, then resume. No interaction with the check of any kind.
Nothing you get today will be taken away.
No runtime date checks exist; any future tier change ships only as a human-published, versioned release. A write-once install timestamp means installs predating any change keep the free tier as it stood at install.
The file matches the screen, always.
Export writes exactly the filtered on-screen set. Distance is stamped at output time against the centre the panel is showing, and the download is held open until Chrome confirms completion, so the file is never truncated.

  1. The file starts with the UTF-8 byte-order mark, so Excel reads accented names without an import wizard.
  2. A phone starting with + would render as #NAME? in Excel. The leading apostrophe is deliberate — and any cell that could execute as a formula is neutralised the same way.
  3. Commas in addresses stay inside quotes, per RFC 4180. Lines end CRLF, per the same.
  4. Blank means Maps did not show it — never zero, never a guess.
